Sabor&Validade Beta 3

Sobre o scanner IA

A Beta 3 combina visão computacional, OCR, busca de produtos e código de barras. Para produtos embalados, o sistema tenta ler o nome da embalagem e procurar correspondências no banco de alimentos. O resultado é uma sugestão e deve ser conferido antes de salvar.

🧠 Como a IA funciona

1. A câmera captura a imagem.
2. MobileNet procura objetos conhecidos.
3. OCR tenta ler textos da embalagem.
4. O sistema pesquisa produtos semelhantes.
5. Os resultados são combinados.
